Мюсли для Windows · проверочная версия

Установим Мюсли. И можно записывать.

Откройте установщик, пройдите короткую настройку — и начните первую встречу. Здесь всё по шагам.

01 /

Откройте установщик

Musli_0.1.7_x64-setup.exe

Откройте файл Musli_0.1.7_x64-setup.exe, который вы получили от разработчика.

У установщика пока нет подписи издателя Windows. Поэтому Windows может предупредить о неизвестном приложении. Скачивайте Мюсли только по нашей ссылке и проверьте имя файла перед запуском.

Если появилось окно «Система Windows защитила ваш компьютер», нажмите «Подробнее». На английской Windows эта ссылка называется More info.

Проверьте имя установщика. Строка «Издатель: Неизвестный издатель» ожидаема у текущей беты. Если файл получен от разработчика и вы ему доверяете, нажмите «Выполнить в любом случае» — Run anyway.

Если предупреждения нет, сразу переходите к установке.

02 /

Пройдите шаги установщика

Нажимайте «Далее» на шагах установщика. Папку установки можно оставить как есть. Дождитесь окончания копирования файлов, затем ещё раз нажмите «Далее».

В последнем окне оставьте «Открыть Мюсли», чтобы сразу запустить приложение. «Добавить ярлык на рабочий стол» создаст ярлык. Нажмите «Готово».

Мюсли устанавливаются для текущего пользователя. Обычно права администратора не нужны.

03 /

Запишите первую встречу

Пройдите короткую настройку в Мюслях. Если Windows спросит о доступе к микрофону, разрешите его для записи своего голоса.

Нажмите «Записать встречу». Остановите запись, когда закончите разговор, и дождитесь расшифровки.

При первой расшифровке Мюсли загрузят модель — около 843 МБ. Это делается один раз. Для следующих расшифровок интернет уже не нужен: обработка идёт на вашем компьютере.

Если что-то пошло не так

Разберёмся.

Найдите своё сообщение.
Ничего отключать наугад не нужно.

Нет кнопки «Выполнить в любом случае»

На корпоративном компьютере запуск может запрещаться правилами организации. Обратитесь к своему администратору.

В Windows 11 приложение также может заблокировать Smart App Control. У этой защиты нет разрешения для одного отдельного приложения. Не отключайте её ради беты — напишите разработчику и приложите снимок сообщения.

Антивирус обнаружил угрозу

Сообщение об обнаруженной угрозе — не то же самое, что «Неизвестный издатель». Не считайте его автоматически ложным срабатыванием.

В Microsoft Defender откройте «Безопасность Windows» → «Защита от вирусов и угроз» → «Журнал защиты». Сохраните название обнаружения и имя файла. В другом антивирусе найдите эти сведения в уведомлении или карантине.

Пришлите их на bdlv@bdlv.me вместе с версией Windows и ссылкой на установщик. Не отключайте антивирус, не восстанавливайте файл из карантина и не добавляйте папку программы в исключения до проверки разработчиком.

Установщик просит права администратора

Проверьте имя и путь запускаемого файла. Если запрос появился неожиданно, пришлите его снимок разработчику до продолжения.

Хочу различать голоса собеседников

Откройте «Настройки» → «Экспериментальное» → «Различать собеседников по голосам». Для этого дополнительно загрузится модель размером около 402 МБ. Функция экспериментальная: после расшифровки проверьте разделение и подписи голосов.

Что с подписью Windows

Пользователю ничего подписывать или покупать не нужно. Подпись издателя Windows (Authenticode) оформляет разработчик; у текущей беты её пока нет.

Подпись обновлений у Мюслей есть: приложение проверяет подлинность и целостность обновления. Но эта подпись не подтверждает издателя для Windows.

Даже после оформления подписи новое приложение может некоторое время вызывать предупреждения SmartScreen: учитывается ещё и его репутация.

Теперь — к встречам.

Напишите на bdlv@bdlv.me: какая у вас Windows, на каком шаге остановились и что показано на экране. Снимок окна поможет разобраться. Текст ваших встреч присылать не нужно.
